# 현재 Agent 실행 프로필 통제 벤치마크

## 목적과 범위

전체 실행 시간 예산을 포함한 현재 Agent 프로필 `agent-c57b1d9c4557c476`의 검색·응답 계약을 다시 측정했다. 프로젝트의 기존 `.env`와 다른 제품이 소유한 PostgreSQL은 변경하지 않았다. PostgreSQL 18.4 임시 인스턴스를 `127.0.0.1`에만 바인딩해, 공식 농사로 공개 문서와 고정 CLI로 수행한 `controlled_local` 실험이다.

이 결과는 실제 사용자 트래픽, 사람 검토 정답률, 운영 비용 또는 배포 성과를 뜻하지 않는다. 자동 생성 실버 질의와 로컬 DB의 상대적인 회귀 감시·설계 검증 근거다.

## Agent 계약 평가

같은 승인 코퍼스에서 고정된 한국어 질문 30개를 동시성 3으로 실행했다. 결과 JSON은 `2026-07-30-controlled-agent-evaluation-current-profile.json`에 보관했고, 동일 실행 30개의 익명 집계 지표가 PostgreSQL `rag.agent_execution_trace`에 기록된 것을 대조했다.

| 항목 | 결과 |
| --- | ---: |
| 표본·최대 동시성 | 30 · 3 |
| 구조적 완료 | 26/30 (86.667%) |
| 안전 보류 `needs_context` | 4/30 (13.333%) |
| 실패 | 0/30 (0%) |
| 인용 계약 보류 | 2건 |
| 모델의 근거 부족 보류 | 2건 |
| CLI p50 / p95 | 14,917ms / 29,753ms |
| PostgreSQL `percentile_cont` p50 / p95 | 15,775.5ms / 28,875.95ms |

CLI는 nearest-rank, PostgreSQL은 연속 백분위 계산을 사용하므로 같은 30개 표본에서도 p50/p95가 소수점·순위 차이로 다르다. 두 기록의 표본 수(30), 완료(26), 보류(4), 실패(0), 종료 사유는 일치한다.

## 해석과 사용 범위

- 포트폴리오에는 “공식 문서 3건·청크 28개·자동 생성 질의 56개에서 lexical FTS의 recall@8 0.875, p95 9.0ms를 재현했고, 현재 Agent 프로필은 30건 중 26건을 인용 계약까지 완료하며 실패 0건을 기록했다”라고 범위를 붙여 사용할 수 있다.
- 이력서 한 줄에는 긴 지연 시간·실버 라벨의 한계를 함께 담기 어려우므로, 이 수치를 단독 성과로 쓰기보다 “측정·승격 게이트를 설계하고 근거 없는 hybrid 승격을 차단했다”는 문장에 상세 근거로 연결한다.
- 이전 실행 프로필의 30건 결과와는 모델·시간 예산·코퍼스가 달라 직접 전후 비교하지 않는다. 성능 개선율이나 상용 완료율로 표현하지 않는다.
